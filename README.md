# 💊 Health Reminder AI Agent

## 📌 Project Overview

Health Reminder AI Agent is a Python-based web application built using Streamlit. It helps users manage their medicine schedules by adding medicine names and setting reminder times in one place.

The application provides a simple and user-friendly interface to organize medicine schedules.

## 🎯 Objectives

* Make medicine schedule management simple.
* Allow users to add medicine names.
* Set reminder times for medicines.
* Display a medicine schedule in one place.
* Provide an easy-to-use web interface.

## ✨ Features

* ➕ Add a medicine name.
* ⏰ Set a reminder time.
* 💊 Save medicine schedule details.
* 📋 View the saved medicine schedule.
* 🎨 Simple and user-friendly interface.
* 🐍 Built with Python and Streamlit.

## 🛠️ Technologies Used

* **Programming Language:** Python
* **Web Framework:** Streamlit
* **Development Tool:** Visual Studio Code
* **Version Control:** Git and GitHub

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/Health-Reminder-AI-Agent.git
```

Replace `YOUR-USERNAME` with your GitHub username.

### 2. Open the project folder

```bash
cd Health-Reminder-AI-Agent
```

### 3. Install the required dependencies

```bash
py -m pip install -r requirements.txt
```

### 4. Run the application

```bash
py -m streamlit run app.py
```

The application will open in your web browser.
